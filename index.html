Turtle quick reference

Common stuff you might want to do.

Move + turn

forward(distance)

Move ahead by pixels in the current heading.

right(angle)

Turn clockwise by degrees.

left(angle)

Turn counterclockwise by degrees.

goto(x, y)

Jump to coordinates without changing heading.

setheading(angle)

Point the turtle in a specific direction.

Pen control

penup()

Lift the pen to move without drawing.

pendown()

Put the pen back down to draw again.

circle(radius)

Draw a circle with the given radius.

Style

speed(value)

Set animation speed (0 is fastest).

pensize(width)

Change stroke width for thicker lines.

color("name")

Pick a pen color (names or hex codes).

Fill + background

begin_fill()

Start filling the next closed shape.

end_fill()

Stop filling and paint the shape.

bgcolor("name")

Set the background color of the canvas.

Etch a sketch starter

Copy this starter and then replace each print with turtle movement.

import turtle as t

def moveUp():
    print("up")

def moveDown():
    print("down")

def moveLeft():
    print("left")

def moveRight():
    print("right")

t.listen()
t.onkey(moveUp, "w")
t.onkey(moveDown, "s")
t.onkey(moveLeft, "a")
t.onkey(moveRight, "d")

t.done()
